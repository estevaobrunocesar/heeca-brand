# HEECA — Brand Kit DEV v1.0
Direção aprovada: **TIPOGRAFIA EXCLUSIVA**

HE = Heloísa • CA = Catharina

## Regra principal
Use os SVGs deste kit. Não redesenhar, distorcer, inclinar, aplicar filtros ou alterar as cores do logotipo.

## Identidade
Minimalista, sofisticada, tecnológica, humana e confiável.
O arco vermelho representa conexão, movimento e evolução.

## Produtos
A Heeca é a marca institucional. Produtos podem ter cores próprias, mas devem herdar tipografia, grid, espaçamento e princípios do Design System.
